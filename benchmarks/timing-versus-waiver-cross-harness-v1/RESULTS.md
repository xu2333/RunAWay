# 《盐汀》续穿工作有没有保留为待办？

37 次实际尝试，收到 36/54 份答复。下表均比较本轮新开的会话。

Codex、Antigravity 各返回 18 份。Claude Code 第一槽为温室题新读法，180 秒超时，未返回任务回答；剩余 17 槽按登记关闭。由此缺少的 9 对进入固定分母，无法判断该端的内容或超时成因。

**《盐汀》** 两个有答复的客户端在两组都保住了续穿白棉线，不催立即做，也没有允许放弃。Codex 新答将五、六列写进“接班待办”，直接说“现在可以做，开始时间由你安排”；它的旧答在“接下来怎么办”中说“现在可……继续穿完”，留下择时空间但没有同样明写。上轮说过“做不做、何时做……由你决定”的是 Claude Code 的已弃用候选。本轮对照用保留的旧读法，且 Claude Code 缺测，因此无法证明当时那份失败已被修复。

**两项回归** 两组都保住砂桥可完全不拍、已拍未知，装帧师的纸样只挡末折。签页出现了一对实际改善：Antigravity 对照说“须查验是否有已签授权页原件”，候选说“必须见签好的授权页”，仍要求馆员核对编号。Codex 两组都没有附加形式要求。

**整份交接** 同期 3 对改善、1 对退步、9 对缺测。三处改善均在 Antigravity：签页去掉原件，雨雀回柜恢复为待办，旧定位纸从受限工作栏回到当前可办栏。退步也在 Antigravity：《双溪听册》把等待新表写成等“传达放行及发送新表”。主评分将两项并列从严计一次额外门槛；若把发送即视为传达，两组仍有差别，但候选的整份分数变为 15/27。每格一份；候选留作实验读法。
