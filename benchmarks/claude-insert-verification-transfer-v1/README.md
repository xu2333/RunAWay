# Claude Code 同张新卡的两种未知

《斜雨纸铺》两只内袋都裁好了，交接时并不知道哪只已塞题签。两种读法沿用 #139 的保留旧法和候选，只换案例，题目仅请接班人写交接单。

> 《斜雨纸铺》这批版画分芦窗套和潮瓦套，两套的内袋都裁好了。芦窗套留店陈列，给店里留着玩的浪纹题签，想塞一张就塞，不塞也照样移到陈列架。潮瓦套要寄走，收件人要袋里恰好一张同款题签。我交代接班的人封潮瓦套之前打开内袋看一下：已有一张就照原样封，空着就从台面取一张补进去再封。晚班只说“两个内袋我都经手了”，没说往哪只塞过题签。两只套还都敞着。

原题：“请给接班同事写一份《斜雨纸铺》的交接单，让他能照着办理。”
