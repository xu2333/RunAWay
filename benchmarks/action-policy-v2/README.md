# Experimental action-label and policy-restatement guidance — unmeasured

The [closed three-source study](../action-revision-stability-v1/MEASURED.md)
finds five j16known choices answered unknown. Source-linked hypotheses include
action fields carrying explanation/scope text and earlier instance background
being promoted to future-policy prerequisites. Repeated reading also varies.

This candidate adds source-only instructions to the unchanged typed graph:

- Prefer complete action names already offered in the source. Preserve a genuinely
  new later action;do not map it to an expired choice. Keep reasons,scope/expiry/
  recovery notes and separate execution arrangements out of the action label.
  Retain their meaning in appropriate conditions,targets,facts or boundaries.
  Never mechanically remove ordering words such as“先”.
- Distinguish a clearly complete future-policy restatement from an action-only
  revision. Complete policies use their own necessary conditions;old concrete
  instance background is not automatically universal. Action-only edges continue
  to inherit parent conditions,including permissions,through the original compiler.
- Independent exceptions keep their own prerequisites;genuine global constraints
  remain. Uncertain classification stays unknown.

Only instructions and a private encoder version tag change. Graph schema shape,
compiler,dense renderer,reader and1536public-character cap remain unchanged.
The wrapper validates its own version then delegates normalized graph content to
the original compiler. This adds **no new structural semantic proof**. Instructions
can be ignored or misapplied;condition/edge classification remains unverified.
There is no automatic string stripping,option matching or source-policy parser.

This guidance is developed after inspecting consumed-study failures. It is not
independent generalization or isolated-component evidence. No old raw cards,
responses,scores,question labels or case-specific feedback enter extraction;
the new generic guidance itself is sent and disclosed. The proposed
[14-call comparison](../action-policy-comparison-v1/README.md) has0actual calls
and requires new human authorization. No production default changes.
