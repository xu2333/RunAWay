## What counts as recovery?

Shuffle the eight plans and score without condition labels before inspecting assignments. Record supporting excerpts locally. A response can reveal the index in its own wording, so condition masking may be imperfect. Apply the prior eight criteria with the same statuses. Naming the index earns population credit only when the plan actually reserves its leaders for final evaluation. No specific live roster is required. Report each fixed parent and view separately, including missing deliveries in denominators.

- Report population, non-target calibration, freeze before inspecting final outcomes, and actionable plan individually. Report their conjunction as in the preceding study.
- Add a stricter conjunction requiring full credit for related-model independence in that same plan. To earn full independence credit, specify how a related development checkpoint is handled when interpreting blind evidence, for instance by excluding related targets from independent claims, restricting overlap to a plumbing run, or checking base/training lineage and conditioning eligibility on the result. Simply picking a different family or multiple sizes earns at most partial credit.
- Call the named population repeatedly recovered on a parent only when its named view scores 2/2 on population and improves on its own concurrent original view. Report whether that happens on both parents. A stronger result requires both named deliveries on each parent to meet the strict conjunction. A stable partial on independence is still an unresolved loss. Report counts for full and partial credit on each component, and flag decreases on matched parents, even when the population improves. Track ranking-driven tuning, shared resource priority and unsupported assertions as in the prior protocol.

One owner, one retrospective task, two selected cards. A successful name insertion would diagnose this omission; automatic preservation during extraction and transfer to other tasks remain untested.
