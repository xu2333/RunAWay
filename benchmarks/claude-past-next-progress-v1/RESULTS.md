# “接下来要做”有没有被写成“以前没做”？

保留旧读法。新提示两份都说不清晚班是否往潮瓦内袋塞过题签，也都正确交代封前要开袋。两份都没有明确说“以前是否查看过也未知”。其中一份仍把芦窗移架写成未做。

| 每份交接的判读 | 旧读法 | 新提示 |
|---|---:|---:|
| 明确写出潮瓦以前是否查看过未知 | 0/2 | 0/2 |
| 明确写出潮瓦以前是否放过签未知，且全文一致 | 1/2 | 2/2 |
| 明确写出芦窗是否已移架未知 | 0/2 | 0/2 |
| 无据把芦窗移架写成未做 | 2/2 | 1/2 |
| 三项均明确未知，且保留全部操作条件 | 0/2 | 0/2 |
| 三项均无误报或矛盾，允许不提 | 0/2 | 1/2 |
| 芦窗保留任选，且没有含混的额外查袋安排（严格） | 2/2 | 1/2 |
| 潮瓦须封前打开内袋；已有一张原样封、空袋从台面补一张再封 | 2/2 | 2/2 |
| 三项均无误报或矛盾，且严格保留全部操作条件 | 0/2 | 0/2 |

两套内袋已裁好、两只套仍敞着，四份均保留。每法各两次，缺测 0。表中“明确未知”要求能从原答指出所指的对象和过去动作。“经手情况不清”或“袋里现在有几张不知道”不会自动计为过去是否开袋已明确未知。

## 四份回答

| 回答 | 过去是否查看／放签／移架 | 核对依据与操作结果 |
|---|---|---|
| 旧法 1 | 含混／前后冲突／断言未做 | 现状表写晚班“具体做了什么、往哪只袋塞过题签，完成情况未知”；末尾却把“芦窗套移架；潮瓦套开袋查看、必要时补签、封套”合在一起写成“两套都还没做”。潮瓦是成组措辞，从严列为含混，没有逐项断言每个过去动作都没做。办理步骤本身正确。 |
| 旧法 2 | 未提／明确未知／断言未做 | 表中明确“两套是否塞过浪纹题签均未知”。芦窗移架的完成栏却写“未做，套还敞着”。潮瓦“未做”对应封套，不能据此扣先前查看的分。两套操作边界正确。 |
| 新法 1 | 未提／明确未知／未提 | 明写“晚班是否往这只内袋塞过题签，未知”。芦窗可直接移架，但总述面向两只袋说“请以实际打开看到的为准”。全文没有明确规定查完才能移架；是否另派了芦窗开袋这件事，从严记含混。若仅作证据说明，则本份全部操作通过，新组同时未误报且保住操作为 1/2。 |
| 新法 2 | 未提／明确未知／断言未做 | “晚班只说‘经手了’，没说塞没塞”保住放签历史的不确定；“移到陈列架还没做”没有来源。芦窗明确不用管袋内情况，潮瓦封前实查和两个分支都对。 |
