# “还敞着”能说明套子在哪里吗？

同一张卡、同一道交接题，各两次独立生成。旧法一次把芦窗移架按未做处理，一次只给出行动许可。新法一次明确写出位置未知，一次也只给出许可。新法的这两份都避开了目标错误，但其中一份把相同的推断用在了另一道工序上。默认保留旧读法。

| 同一份交接中的表现 | 保留的旧读法 | 新提示 |
|---|---:|---:|
| 明确写出芦窗是否已移架未知 | 0/2 | 1/2 |
| 未说当前位置，仅有办理建议 | 1/2 | 1/2 |
| 无依据将芦窗移架当作未做 | 1/2 | 0/2 |
| 位置说法含混或冲突 | 0/2 | 0/2 |
| 避免无依据的位置判断（包括未提） | 1/2 | 2/2 |
| 芦窗无需核查即可移架，题签可选 | 2/2 | 2/2 |
| 潮瓦封前仍须打开内袋 | 2/2 | 2/2 |
| 有一张原样封，空袋从台面补同款一张再封 | 2/2 | 2/2 |
| 两内袋已裁好、两套仍敞着 | 2/2 | 2/2 |
| 整份交接无失分（未提位置也可通过） | 1/2 | 1/2 |

## 原答中的区别

| 回答 | 位置判断与其它得失 |
|---|---|
| 旧法 1 | “现在可以做：直接移到陈列架”只说明许可。现状表记录袋已裁、套敞着和塞签未知，没说位置。 |
| 新法 1 | 未陈述位置。潮瓦的“完成情况”却写成“这一步的核对和补签，目前没有任何完成的依据，视为未做”。实际指令仍要求开袋，且只在空袋时补签，因此操作分保留，整份失分。 |
| 新法 2 | “是否已移到陈列架：原文没有说明，未知。目前只知道它还敞着。”同一份也保住两只套的核查边界和两条封套分支。 |
| 旧法 2 | 状态表把“潮瓦套封口、芦窗套移架”并列为“当前都敞着，按未做处理”。敞着足以说明当前未封，却不足以断定套子仍未移架。 |
