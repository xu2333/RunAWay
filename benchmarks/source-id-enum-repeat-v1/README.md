## Failure classification is shared

Both methods first validate the same structural response schema. An undefined
ID is a **binding-invalid product under either method**,including when it also
violates the enumerated request. Record request-schema conformance separately;
reject the product and skip only its own two readers,keeping15missing. This
preserves the existing reference rejection class and does not admit,normalize
or repair a bad ID. A product that passed binding but failed the request enum
would close the scope as an inconsistent contract.

Control,transport,shared structural wire/schema/decode,unknown usage,model,
input/runtime or owned-guard failure closes the remainder. Unused slots expire.
No retry,manual patch,resumption,best-of,slot replacement or old-budget reuse.
The evaluator does not feed observed errors back to either review method.
