# Fixed-card partial-information results

The separately authorized scope is **closed**: 37 actual local inference attempts,
37 recorded inference children, zero new extractions, no missing usage or expired
slots. All eight prior cards remained verbatim. No retry, repair or replacement
was made. Four new full-source controls passed all 16 own cases in both orders
and showed a primary-known gain over the new no-memory control before any view
was read. The [original protocol](README.md) and its frozen preparation remain
unchanged; the preparation itself never grants service authority.

## Main endpoint: 48 partial-information cases

Each person/case must match across both fixed parent versions × two reads × two
option orders (eight answers). These are correlated repeated answers, not new
independent people or fresh extractions.

| Primary endpoint | Compact card | Own equal-character raw tail |
| --- | ---: | ---: |
| All partial cases | **48/48** | **36/48** |
| Missing context but unique common choice | 16/16 | 4/16 |
| Conflicting context or override branches: U | 32/32 | 32/32 |
| Missing cases | 0/48 | 0/48 |

The two unknown cohorts each retain 16/16 for both views. The agreement cohort
retains 16/16 for cards and 4/16 for tails. An always-U policy would score 32/48
on the primary endpoint while getting **0/16 known choices**. That is a logical
baseline from the fixed reference, not an extra model run. Unknown accuracy
alone therefore cannot establish useful retention.

The 12 primary tail losses all answer U in all eight positions despite having
a common source-licensed choice. Both parent versions separately reproduce the
same primary endpoints; no primary answer-vector differences are observed.
The tails have insufficient or incomplete source context for those choices.
This is not evidence that the full-source reader cannot handle the questions.

## Complete anchors stay separate

| Auxiliary endpoint | Compact card | Own raw tail |
| --- | ---: | ---: |
| Complete-condition anchors | 16/16 | 4/16 |
| Combined primary + anchors | 64/64 | 40/64 |

The combined result is not the primary 48-case result. Parent-version tail
counts are 43/64 and 40/64: the three differences are complete friend-support
anchors for `auri`, `bryn` and `dune`. In each, parent version 0 yields four
correct answers and version 1 yields four U answers. Their suffix lengths differ
(735→694, 737→730, 750→717 characters), so these are changed materials, not
identical-input reader variation. No within-parent repeated-request difference
is observed. These few observations do not prove population stability or a
causal length-only effect.

Across primary plus anchors, 24 tail cases fail jointly: 21 answer U throughout
and 3 vary only between the fixed parent versions. The archive replay lists
all cases, their eight answers, primary/anchor labels, cohort and loss class.
The old 28/64 fresh-scene tail result and this 40/64 result have **different
questions, reference mixtures and denominators**. They are not evidence that
the tail method improved.

## Interpretation

The fixed cards support this explicit possible-context task: they preserve both
known common choices and justified U answers. This is more specific than the
previous test of targets absent from the source, and is not established by an
always-U strategy.

It remains a **post-hoc diagnostic on four consumed fictional people and eight
old cards**. Labels join the old author reference; this is conditional logical
consistency, not independent semantic adjudication. Candidate contexts are
exhaustive by task premise, not a verified account of real missing context.
The question contract explicitly requests a unique common choice; it is not a
general decision rule for uncertain real-world planning. The study does not
establish fresh generation stability, real-person fidelity, cross-provider
transfer, RIG, statistical independence, an optimal compression frontier or a
production-default promotion. Older failures and unresolved limits remain.
