# Claude Code 复测：过去做没做，需要先查吗？

《折岸拼景》的搭档说过“知道可以拍”。这能证明他知道自己可以拍，也把“已经拍过吗”留作未知。上轮两组各有一份交接单又给接班人派了核查任务。本轮对照组沿用上轮保留的旧读法。候选组只在同一份项目规则末尾追加以下通用提示。

> 完成情况未知时，可以把“未知”作为交接结论。只有原文要求查明，或下一步明确取决于这件事是否已经做过，才把查明列为待办或前提。

两种读法各做三道原题，每题两次。《折岸拼景》检查选拍、未知和有无额外核查，《盐汀》检查续穿义务与时机，声音档案馆检查放行条件。每份交接同时核对其它原有条件，评分覆盖正文和结尾清单。上轮的旧答与评分保存在原目录。

每次在独立临时 Git 项目中安装一条 `.claude/rules/runaway.md`，以 Claude Code 的 `sonnet` 运行对应原题。禁用会话持久化、工具和自动记忆，只加载项目规则。180 秒超时，运行故障后关闭余量。
