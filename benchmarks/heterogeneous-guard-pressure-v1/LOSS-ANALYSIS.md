## Offline format improvement:997to768without editing declared fields

The public replay script includes a separate **development-only template
prototype**. It recognizes a narrow ordered shape: two ordinary threshold rows
plus one higher-priority low-threshold exception sharing the first action. A
counted Chinese legend describes the rules once; each group supplies its literal
scope, any extra ordinary guard, threshold with unit, exception predicate and
both complete actions. Scope prerequisites remain necessary for every branch;
ordinary-only guards are not inherited by the exception. Name, tagline, unknown
text, full action names, aliases, conditions and priorities are retained.

Applied to the **unchanged actual slot14 graph**, this deterministic rendering
produces **768whole Unicode characters**, compared with its997character ordinary
diagnostic expansion. Restoring it reproduces the same ordered public fields
exactly. No source predicate, action, alias or unknown line is manually removed.
All twelve complete action names remain present. The guide and escape definitions
are inside the counted card; readers would not receive an external decoder.

This layout was developed **after observing the failure**. It was not part of
the authorized16requests, and **no LLM has read it**. It establishes field-level
reversibility and a concrete budget-fitting candidate, not restored reader
fidelity or automatic source-only generation success. The two large-budget
parents still exceed768under this prototype; not every card benefits enough.
Unsupported row shapes or oversized outputs fail rather than being changed.
The shorter author fixtures also fit, but author fixtures are not model results.

Slot14's current decision labels can be matched to the supplied option names;
that does not test unprompted reconstruction of every action detail. Exact-name
diagnostics are navigation, not automatic semantic judgments. Literal projection
round trips likewise do not prove that the graph captured every source constraint.
For example, the richer large-budget card explicitly records the nonnegative
integer domain; this benchmark does not probe out-of-domain quantities.
