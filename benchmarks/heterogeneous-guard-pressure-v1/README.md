# Heterogeneous guard-amendment pressure: preparation, not model results

The preceding [direct768 study](../fresh-direct-768-v1/RESULTS.md) retained every
case, but used repeated action names, thresholds and branch structure. This
offline follow-up varies the information within each person: six complete action
pairs, six units and thresholds, six gates, six local exceptions, condition-only
amendments, old/current names and distinct copies.

**No model calls have run on these sources. No execution budget is granted by
this package.** `plan.py` freezes a proposed new 16-attempt study; `engine.py` has
only an injected backend and requires a fresh exact human grant in real mode.
Old scopes, inputs and measured observations are unchanged.

## Concrete capacity finding

Two newly authored fictional source records, 48 messages each, have author-built
current graphs. The existing source-ID compact encoder accepts both at 1536:
their uncompressed dense cards are 974 and 977 characters. At 960 the same renderer
can produce 954 and 957 characters. Both complete author fixtures are rejected at
768 (and at 896); nothing is truncated or moved into unknowns.

This shows a limitation of these exact author representations and this
unchanged rendering algorithm. It is **not** an information-theoretic lower
bound, a model-generated omission, a failed extraction, or proof that no better
self-contained 768-character representation exists. The archive retains no new
model answers because none were requested. See `preflight.synthetic.json` for
the reproducible offline observations.

## What the cases isolate

| Amendment | Source commitment | Distinguishing check |
| --- | --- | --- |
| Threshold only | E.g. 8→13 minutes; both actions and other guards unchanged | At the old boundary choose the current low-amount action; at the new boundary choose the high-amount action |
| Guard replacement | New copyright/license guard replaces the old one across all branches | Old guard true and new guard false must yield U |
| Local relaxation | A guard is no longer needed in the priority exception; ordinary branches retain it | Missing/false guard with the exception is known, without it is U |
| Scope and evidence | A rename is identity; a copy is separate; tool status is not confirmed | Old alias retains the choice; copy and actual implementation stay unknown |
| Partial information | Only source-supported completions, without inventing missing facts | Missing amount can still be known when every branch agrees; missing reviewer can leave conflict |

Current amendments explicitly restate all current choices. Therefore this does
not test partial retractions, implicit revisions or cross-project correlated
uncertainty. The full action names are the response targets, not execution order.

Hand-authored answer tables are cross-checked against a finite policy and the
complete public projection of the author graphs. Five constructed projection
damages change 12, 4, 8, 12 and 44 cases respectively: stale thresholds, obsolete guards,
incorrect guard reinstatement, erased gates and erased guards. Those are
calibration checks, **not observed model losses**. The small predicate interpreter
accepts only the author's literal vocabulary; it does not grade arbitrary model
prose or establish semantic fidelity by itself.

## Proposed 16-attempt comparison

Two no-memory banks + two full-source controls, then four independent
source-only extractions and eight card reads. The same existing compact
encoder generates one card per person at 768 and 1536 characters; each card is read
twice with both option orders. Extraction never sees questions, author graphs,
reference tables, scores, another generation or old model output. Readers receive
only their own complete card and 164 public question forms.

This is a first-pass mechanism diagnostic, not a repeated-generation stability
study. No second extraction is selected or substituted after seeing a result.

Each budget retains a fixed 164 person/cases (72 known, 92 unknown). All four answers
per case must be correct. An invalid parent skips only its own two reads and
keeps its 82 cases missing, not U. A larger-budget success paired with a missing
768card is reported as missing, not a recovered semantic choice. Both full
controls must retain all 82 cases in both orders and improve known choices over
their corresponding no-memory bank before extraction. Fatal failures close the
scope; no retry, repair, resume, replenishment or reuse. A 16-local-attempt limit
is not a token or monetary limit. Child timeout remains 180 seconds.

Only two fictional people are person-level units. The author knew prior
experiments and wrote the references: no independent semantic-gold, holdout,
human-taste, cross-provider or population claim. The budget changes both the
extraction request and rendering allowance, so this is not a pure-codec causal
comparison. Production defaults are unchanged.

## Reproduce offline

```sh
python3 -B benchmarks/heterogeneous-guard-pressure-v1/check.py
python3 -B benchmarks/heterogeneous-guard-pressure-v1/plan.py --out /tmp/guard-pressure-packet
```

Both commands perform zero model calls. The packet freezes 8 exact static
requests, 8 own-parent read slots, all 96 fictional messages, 328 unique public forms,
164 case references, author navigation and implementation fingerprints. A new
finite 16-attempt authorization bound to its manifest and exact successful three-platform
CI is still required. Tests of the injected runner are explicitly simulated;
their oracle responses never become evidence of model fidelity.
