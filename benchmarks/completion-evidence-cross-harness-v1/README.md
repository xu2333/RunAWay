# 交代过的动作，交接时能否留作完成情况未知？

这一轮使用《雾港字盘》等九份既有虚构卡和原任务。在 Codex、Claude Code 和 Antigravity 中用全新项目和会话对照两种读法。对照组复用上一轮的放行人和用料提示。候选组只在其后加一段通用指导：

> 交接时逐项区分“交代了什么”和“有证据表明做到了什么”。只有材料明确说明同一对象的这一步已经完成，才写已完成。有交代但缺少完成依据，就保留原要求，明写完成情况未知。已证实的进度照实保留，无需重做；也别把一项进度未知变成其他动作的新前提。

## 怎样判读

《雾港字盘》的主指标要求同一份交接保留保管要求，并明确写出完成情况无证据。只转述指令或略去状态单独记分。另列无据断言已做、断言未做或要求无条件重做，以及前后矛盾。条件性补做和无条件重做分别判读。另检查各版的已知印数、两块竖题未开印、恢复范围及各自签名，并报告三项在同一答里都保住的份数。

《双溪听册》有真正完成的备份和回读，用于查找过度保守和重复派工。《盐汀》继续核对放行人和白棉线；温室、声音档案馆、拼图、字幕四题继续核对额外通知或排班门槛。其余判分沿用原九题的 30 项。一次观察只计一份答复；同一模型相同题目没有重复采样。
