# Lossless dense public layout — offline projection proof, reader untested

The [closed budget-aware probe](../budgeted-table-probe-v1/MEASURED.md) produces
two structurally legal ledgers whose public cards still fail1536characters:
1889and1687after the old lossless packer. Both remain failed experiment products.

This new renderer changes no source annotation. It validates the same ledger
and source quotes through the unchanged owned-condition/grouped checks, then
encodes the **literal public semantic projection** more compactly:

```text
@shared scope
question|condition&condition→action
1:question|exception condition→action
?unknown boundary
```

The counted guide defines question matching, scope and condition conjunction,
priority/default0,conflict/unknown behavior and escaping. Reserved characters,
priority-looking prefixes and newline/carriage-return/tab remain reversible.
A grammar-aware exact-phrase packer may add `先展开={"①":"literal phrase"}`
as a **counted public JSON dictionary**. Values are JSON strings; newlines and
delimiters cannot silently end a definition. Dictionary symbols cannot collide
with original symbols. Decoding uses only public text,without a private report
or external dictionary. All original names and words are restored,not paraphrased.

On the two frozen prior ledgers,the derived dense cards are **1536and1413**
characters,including guide/dictionary,versus the prior failures1889/1687.
The public fields reconstruct exactly,and rendering them through the original
grouped renderer recovers the complete old literal view. Private evidence quotes
remain private as before; this is not a claim that public text contains the
whole private ledger. This is a new layout/dictionary bundle,not a pure layout
or dictionary-candidate ablation and not a new neural compression result.

The first dense view uses3dictionary entries; the second needs none. The first
fits exactly at the cap. No claim of universally minimal length or performance
on unseen sources. No old source record,failed output,skip or denominator is
replaced. **No model has read these dense views yet**. Program equivalence does
not prove LLM interpretation,source entailment,privacy or behavioral fidelity.
An experimental standard `portable_expression` can carry the resulting text,
but production defaults and original profile formats remain unchanged.

unknowns,dictionary decoding without private metadata,symbol collisions,
malformed syntax,source-role/quote rejection and hard budget failure. Four
derived-evidence controls reject changed parents,projections,old failures or
claims that offline formatting proves fidelity/repairs a closed scope. They
perform0new model calls. The [next14-call read-only plan](../dense-layout-probe-v1/README.md)
