This candidate addresses **freehand quotation failure**. The model chooses source
IDs rather than retyping evidence. A schema-directed resolver retrieves each
entire source message, then runs the original scope-alias/accounting binder and
compiler unchanged. Raw graph choices, conditions, priorities, object ownership,
alias relations and source accounting remain model decisions. No new source is
inferred, clipped or supplied to the reader. Public whole-card budget remains1536.

The new wire enumerates actual source IDs and forbids `quote`. After deterministic
expansion, every old string limit, role check, action/name witness, bidirectional
reference, chronology and public-budget guard still applies. Oversized full
messages are rejected by original limits; this is not yet an arbitrary-length
input solution. The typed traversal distinguishes a legitimate accounting key
named `source_id` from an evidence anchor. No production default changes.

This changes evidence granularity from a model-selected excerpt to its complete
source message. A full message can mention several candidate actions; an ID's
existence is not proof of an endorsed choice or true identity. The original
literal guard also accepted complete messages. An explicit negative fixture
retains that existing semantic-classification limitation, and all semantic and
behavioral verification flags remain false. A valid graph is not certified
complete or faithful. Same public text for an existing graph is not evidence
that new automatic generations will retain the same decisions.

The timeout record also contained a `turn.completed` event. That does not prove
a usable final card, diagnose why the child failed to return, or demonstrate
that shorter evidence will fix it. The proposed comparison keeps the existing
one-child180s transport and terminal-failure rules. No timeout is reclassified
as success and no historical card or score is repaired.
