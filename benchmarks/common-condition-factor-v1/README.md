# Shared-condition factor: a smaller reversible public card

**Offline prototype only. Model-reader fidelity is unmeasured. No default or
existing card changes, and no new service authority.** The preceding
[condition-erasure diagnostic](../orthogonal-condition-diagnostic-v1/RESULTS.md)
showed that removing material guards preserved44old cases yet produced false
choices on16crossed cases. This candidate preserves every guard while reducing
repeated text.

The codec finds the exact ordered prefix of conditions shared by **every** rule
in **every** scope. It writes that prefix once as a public instruction:
`每条规则另须本题所问项目满足=[...]`. Each rule still requires that prefix in the
project/context of the question. It does not require all projects to satisfy it
simultaneously. A rule without that prefix prevents hoisting; no synonyms are
merged and no predicates are paraphrased, reordered or deleted. If the instruction
costs more than it saves, the original card is retained.

The complete header, guide and common-condition instruction count toward the
whole-card ceiling. The offline inverse reconstructs the exact original dense
public projection, including condition order, scope names and aliases, question,
action, priority and unknown notes. Existing counted dictionaries and escaped
text are supported. An oversized card fails; nothing is truncated.
