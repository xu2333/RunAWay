# Fresh trajectories → whole768-character cards

**Prepared, unapproved, zero new model calls.** This is a source-only experiment
proposal, not a measured compression result. It does not reuse an old card as
the extraction input. Production defaults and old evidence are unchanged.

Four new fictional people (`puffin`, `stoat`, `mallow`, `sorrel`) each have six
interleaved projects: 54 messages, including 36 user messages. The two people
in each family make counterfactual choices under the same question bank. They
are newly authored development fiction, not independent human or semantic gold.

## What can go missing

- One user message makes two choices. Classifying that source is insufficient
  if only one choice becomes a node.
- The cutoff includes exactly20minutes. A later action revision affects only
  the reviewer-present short-time exception.
- In the strict family, material readiness remains necessary everywhere. In
  the released family, only that narrow exception stops requiring materials;
  ordinary branches retain the material guard.
- Some missing details leave a unique choice; others must produce unknown.
  Missing material is therefore not a universal abstention rule.
- Old names, qualified same-name projects, lookalike copies, assistant advice
  and tool-reported implementation states must retain separate ownership.

All sources, questions and references are deterministically reconstructed by
`corpus.py`. Public questions contain their scenario facts and options; source
rules are in the source or candidate memory, not in a separate reader decoder.
The hand table and finite policy agree. This is construction consistency, not
independent semantic acceptance. Author source links are navigation only.
