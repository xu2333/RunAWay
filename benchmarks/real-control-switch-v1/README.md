# Does a source-attributed change of method survive compression?

The [previous comparison](../../docs/results/real-control-boundary-v1.md) exposed an ambiguity in asking for one important boundary. Both cards selected a real constraint. Neither specified which implementation to use under which conditions. This prospective comparison changes the extraction instruction only. The [addition](encoder.py) asks for the situation where the existing method works, a concrete trigger for switching, the replacement method and who proposed it. It permits unknowns. No game, action, controller, source identifier, example answer or case-specific rubric appears in the added instruction.

## Assessment before unblinding

Use the [frozen delivery criteria](../real-control-boundary-v1/README.md#frozen-assessment) for usable plan, cross-game transfer, meaningful control distinction, multi-touch and misattribution. A usable plan must operationalize transfer and distinguish discrete interactions from continuous control with an execution consequence in the same delivery. Preserve the original joint outcome. In addition, score **explicit provenance** separately on each plan: assistant proposal tied to this distinction, unspecified, wrong attribution/status, or missing output. A reader may reason to the same distinction unaided. A correct plan alone cannot show that the card carried either the distinction or its provenance.

Lock local excerpt-backed judgments on shuffled plans before opening labels or inspecting cards. Then audit each detailed profile and exported card separately for (1) where the existing approach works and what that approach is, (2) the concrete circumstance that calls for switching, (3) what replaces it, and (4) who suggested that specific switch and its provisional status. Credit a complete card only when all four components describe the same grounded contrast and the owner's cross-game goal is preserved. Generic disclaimers about assistant suggestions are insufficient. Distinguish supported, partial, absent, contradicted and missing. Record whether information first disappears during extraction, rendering or use. The stronger end-to-end criterion requires a complete attributed card and two jointly successful plans with no false attribution. For each encoder both independent cards must pass; report component counts, single-card results and every missing read. Observed equality is a valid result.

Check displacement against the concurrent baseline, the earlier cards and the source. Report each card's phone-first/tablet alternative, demonstration before takeover and uncertainty about readiness, one-game start, progress without hardware, guided flow with one or two buttons per page, dissatisfaction with appearance, limits on inferring visual taste, and uncertainty about local versus assisted processing. Record lost qualifiers as well as outright omissions. Do not penalize a plan for omitting unrelated card content. The grader knows the case and prior loss. This is a targeted mechanism test and provides no estimate across users.
