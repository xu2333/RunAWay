    怎样在电脑上用这个包？

    1. 把 ZIP 传到电脑，单独解压，找到 install.mjs。
    2. 在它所在的文件夹打开终端，用 Node.js 22 或更新版本运行下面的命令。把引号里的路径换成你的项目目录。
      node install.mjs --project "/你的项目目录"
    3. 在刚才选的项目里，新开一个会话。
